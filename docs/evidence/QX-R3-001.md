- The production root no longer imports or constructs `createLonelyStarWorld`.
- `ProductionGfxRuntime.update(snapshot)` accepts the real projected journey
  seed, story time, phase/shot, position, velocity, pulse ledger, `answerAt`, and
  finished state on every animation frame.
- The existing v2 Foundation owns initialization, resize, quality, telemetry,
  and disposal. The production wrapper owns only the journey-facing contract.
- QA may request forced WebGL2 locally; normal production requests
  WebGPU-preferred and retains the adapter's real fallback behavior.
- Runtime evidence exposes actual backend, requested backend, quality, plan
  digest, live render snapshot, and resource-owner counts without mutating the
  deterministic simulation.
- The production import-graph test starts at `app/page.tsx` and proves
  `src/game/world.ts` and `src/game/visual-assets.ts` are absent while the v2
  production and Foundation runtimes are present.
- Reduced motion chooses static renderer quality profiles, and high contrast is
  applied to the canvas world as a presentation-only filter. Neither changes
  the deterministic journey state or Twinkle ledger.
