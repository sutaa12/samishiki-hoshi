## Contract proven

- `RenderHost` owns the sole frame loop and the lifecycle
  `new -> initializing -> ready -> disposing -> disposed`, with terminal
  `failed` for initialization, frame, or live-backend failure.
- Initialize and dispose are idempotent. Partial initialization unwinds features
  in reverse order, then materials, uploads, registry, and backend.
- A late backend event waits for an in-flight asynchronous render before cleanup,
  so graphics resources are not destroyed during submission.
- Each `JourneyRenderSnapshot` is copied and recursively frozen before a feature
  observes it. `storyTime` is distinct from the visual frame clock.
- Material and feature passes are collected and passed to `compileAsync` before
  `ready` and before the first submitted frame.
- The raw `WebGPURenderer` is private to `ThreeRenderBackendAdapter`. Requested
  policy, actual renderer backend, API exposure, diagnostic navigator probe,
  compatibility mode, and lab status remain separate facts.
- Browser evidence covers forced WebGL2 and host Apple Metal actual WebGPU. Both
  initialize, precompile, render, fully dispose, and recreate with a fresh canvas
  ownership unit.
- Forced-WebGL2 same-canvas reconstruction was deliberately rejected after Three
  r185 reproduced an invalid disposed-context state. The route replaces the
  canvas along with the renderer; the browser gate proves the old canvas is
  disconnected before generation 2 becomes ready.
- Synthetic device loss transitions the host to `failed`, stops the loop,
  detaches resize and event bridges, removes runtime subscribers, disposes the
  scene, and returns every tracked resource counter to zero.
- The GFX-002 report includes the unchanged five GFX-001 cases; all remain green.
- GFX-002 uses a dedicated Playwright config and report so its run cannot
  overwrite the immutable GFX-001 evidence file.

## Limits and remaining gates

- This route is a lifecycle laboratory, not the game, a Hero Slice, or a visual
  fidelity claim. The Notion gameplay images remain the future Slice target.
- The single contract scene is not the seven-family material library, Linear HDR
  pipeline, temporal history system, world generator, worker/chunk lifecycle, or
  adaptive-quality controller. Those remain GFX-003 through GFX-006.
- Single-run backend observations are not performance acceptance. Reference
  hardware remains `HARDWARE_PENDING`.
- Ten actual create/render/restart/dispose cycles remain R2-G6 work. This ticket
  proves one explicit dispose plus recreation and failure cleanup on each accepted
  browser path.
- Main integration, saved Sites state, public deployment, and contest submission
  remain frozen.
