## Contract exercised

- Exactly seven descriptor-backed TSL families exist: water, terrain, foliage,
  concrete, metal, glass/foil, and alien. Each actual backend receives a closed
  full/lean variant inventory; no `ShaderMaterial` or copied demo shader enters
  the v2 runtime.
- Every reachable material pass is compiled inside every reachable profile's
  actual half-float target and temporal MRT before ready. Runtime material and
  graph signatures are collision-free and checked before submission.
- Scene output stays Linear HDR until the one pipeline-owned ACES and sRGB
  transform. Water/glass transmission is expressed by TSL alpha inside that
  graph; Three's framebuffer-copy transmission path is disabled because its
  BGRA8 viewport texture is incompatible with the RGBA16F post-process target.
- One temporal owner controls depth/velocity history and exact invalidation for
  initialization, resize, backend/profile changes, seek/restart, camera
  discontinuity, S21/S23 cuts, and the final life-light injection. Forced
  WebGL2 selects the non-temporal fallback where velocity/MRT is unavailable.
- Attach, quality, resize, invalidation, precompile, submit, and dispose use
  bounded captured input and exclusive operation admission. Partial failures
  keep exact cleanup obligations and allow post-settlement retry without
  double disposal or false zero ownership.
- Material, pipeline, and backend failure evidence is detached, deeply frozen,
  stackless, and subject to shared depth/node/width/text limits across cleanup
  roots and retries.
- In the actual WebGPU run, five profile graphs and both WebGPU material
  variants were ready before use. Low, Balanced, and High transitions retained
  the same ready-time program count with `programGrowthAfterReady = 0`.
