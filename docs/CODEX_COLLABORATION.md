# Codex collaboration record

## AI workstream

- Primary Codex agent: source-of-truth intake, repository/GitHub creation, implementation integration, deterministic QA, browser QA, Sites release, and evidence binding.
- Independent architecture agent (SolMax): read-only Notion/code review; established one-way `pure simulation → world plan → Three renderer/audio`, exact 24-shot precedence, performance budgets, and artifact-only final-review requirement.
- Compliance agent (SolMax): read-only official event/terms/privacy comparison; separated official requirements from internal quality targets and identified the human consent/submission gates.
- Scoped gameplay agent (Terra): pure deterministic 180-second state, 24-shot score, pulse ledger/hash, and 1,000-seed route properties.
- Scoped rendering agent (Terra): procedural Three.js world and generated Web Audio, integrated and then revised from visual QA.
- Final reviewer: pending artifact-only isolated review after the release candidate is hash-pinned.

## Image-generation record

- Mode: built-in image generation, one call, no input image.
- Output: `public/og.png`, normalized to 1600×900.
- Purpose: social preview and contest thumbnail only; the runtime game remains code-generated.
- Prompt summary: living Earth with asynchronous life lights; a small luminous winged droplet; exactly three iridescent curved ribbon shells around a central void; hopeful deep-space composition; no text, logo, watermark, humans, cockpit, panels, thrusters, weapons, or rescue beam.

## Evidence philosophy

- Product behavior comes from the Notion plan and the local executable specification.
- Automation evidence is command- and SHA-bound.
- Independent visual judgment is isolated from implementation context.
- Public URL health, human play understanding, rights/consent, hardware performance, and final contest submission are not collapsed into one status.
